## 推奨する進め方

1. **CORE-01（購入チェックの連続タップ対応）を次の実装タスクにする。** 同時にユーザー端末でQA-01〜03の既存機能を確認する。
2. CORE-02/03の共通設計と移行方針を作り、同じ週の複数回の買い物、調理時の在庫消費を順に実装する。
3. 実使用の結果を見てQA-04・UX-01を進め、UX-02とAI-01は必要なものから選ぶ。
4. AI直接接続・外部自動取込・店舗マップ・同期は別タスクとして扱う。

今回は残件整理とドキュメント更新のみ。アプリ機能・IndexedDBの保存データ形式は変更していない。新機能の実装や実機検証を完了扱いにしていない。
