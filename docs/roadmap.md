# ロードマップ

## MVP

- 日本語5タブ、レシピCRUD・検索・人数換算、週間朝昼夜献立・移動・日別人数。
- 在庫CRUD・期限・予定残量、材料自動集計、直接購入品、数量調整、カテゴリ別チェックと保存、購入分の一度だけの在庫反映。
- IndexedDB、バージョン付きJSONの検証・確認・復元、ファイル共有/ダウンロード、最終バックアップ、永続ストレージ要求。
- React/TypeScript strict・Vite・Tailwind・Dexie・Zod・PWA・Vitest・Playwright・GitHub Pages CI、GPLv3。
- AIProviderの契約、プロンプトコピー、構造化JSON手動取込。

## 次の開発

ホーム画面へのアプリ保存はユーザーから完了報告あり。オフライン・データ保持・ファイル共有・復元・更新は引き続き実機確認が必要。

1. 購入チェックの連続タップ対応と、オフライン再起動・バックアップ/復元・更新時のデータ保持を優先する。
2. 同じ週の複数回の買い物と調理時の在庫消費を、需要・購入・消費の共通設計とデータ移行を含めて実装する。
3. 実使用から食材名・カテゴリ設定、レシピ整理、他ブラウザとアクセシビリティを改善する。

残件の優先度、現状、完了条件、着手条件は[backlog.md](backlog.md)にまとめている。

GitHub Pagesへの初回公開は完了。https://ha-newbie.github.io/otsukai/ を利用でき、以後はmainの更新で自動公開する。
