# URL取込の実行方法とエラーコード

調査・修正日: 2026-10-15。対象: https://cookpad.com/jp/recipes/18472521

## 原因

指定URLはHTTP 200でHTMLを返す。`Origin: https://ha-newbie.github.io`を送った応答にも`Access-Control-Allow-Origin`はない。URLの誤りや、材料欄が存在しないことが原因ではなく、PWAの別オリジンから応答を読むための許可がない。HTTP 200でもブラウザはJavaScriptへ本文を渡さない。

GitHub Pagesは静的配信であり、URL取得処理はユーザーのブラウザで動いている。Pagesのサーバーがクックパッドを取得しているわけではない。Service Workerも同じCORS制約を受け、`no-cors`では本文が読めない。参考: [MDN CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)。CORSを迂回するプロキシ、Cookie取得、アクセス制御や有料表示の回避は実装しない。

旧実装には別の問題もあった。`redirect:error`でCORS対応サイトの通常転送まで拒否し、通信失敗を一括した文言で表示していた。今回は`redirect:follow`へ変更し、CORSの範囲内で転送する。さらに指定レシピで使われるグループ記号「◯」を材料名から除去する対象に追加した（「○」とは別の文字）。

## アプリでの実行方法

| 方法 | 実行場所 | 条件・操作 |
| --- | --- | --- |
| URLの直接取得 | おつかいを開いている端末のブラウザ | HTTPS・CORSを許可したサイト。通常転送も許可が必要。Cookieなし。 |
| クックパッドのページ取込 | Safariでユーザーが開いた元ページ | iPhoneの共有メニューからショートカットを実行し、材料だけをコピーする。おつかいへ戻して結果を貼り付ける。 |
| HTML・JSON | おつかい内 | 端末内で解析。表示中のDOMへHTMLを追加せず、資産も読み込まない。オフライン可能。 |
| 本文・AI | ユーザーが開いたChatGPTとおつかい | 手動コピーと回答の検証。アプリからAIへ自動送信しない。 |

**クックパッドのURL入力だけの自動取得は、現在のサーバー不要のPWA構成では未対応。** URLを入れると直接取得を推奨せず、Safariでの取込手順を示す。直接取得ボタンは診断用と明記した。取得の実行中は「処理中」と表示し、保存と区別する。

### iPhoneの初回設定

1. おつかい → レシピ → レシピを取り込む → URLを入力 →「Safariでの取込手順を開く」。
2. 「初回だけ：ショートカットの作り方」を開き、実行用JavaScriptをコピーする。
3. iPhoneの「ショートカット」で「おつかい材料コピー」を作成する。共有シートに表示し、入力は「SafariのWebページ」にする。
4. 「WebページでJavaScriptを実行」を追加し、入力をショートカットの入力にする。既定コード全体をコピーしたコードへ置き換える。
5. 次に「クリップボードにコピー」を追加し、内容を直前のJavaScriptの実行結果にする。

次からは、Safariで元レシピの材料を表示 → 共有 →「おつかい材料コピー」→ ホーム画面のおつかいに戻る →「ページ取込」へ結果を貼付 → 解析・確認・保存。URL文字列だけをショートカットへ渡したり、おつかい上で実行したりしない。設定・許可・OSによる表示差は[Apple公式手順](https://support.apple.com/ja-jp/guide/shortcuts/apdb71a01d93/ios)を参照。

コードは元ページの材料・人数・タイトル・著者・元URLだけを読み、通信・Cookie読取・ページ変更を行わない。結果は100KB以下の`otsukai-recipe-page` v1。アプリが取得元と入力URLのレシピIDを照合し、エラーや未知形式を検証する。作り方や写真は受け取らない。自動で保存せず編集画面を開く。認証情報を含めず、DB/バックアップ形式も変更しない。

**iOS実機のショートカット設定・共有操作はこの環境では未検証。** 配布する本番JavaScriptをブラウザ上の元ページで実行し、結果をアプリで解析・保存する部分は自動検証する。署名済みショートカットの自動インストールは提供していない。Safariとホーム画面PWAの保存領域が異なる場合があるため、元のホーム画面アプリへ戻って貼り付ける。

## 診断とコードの運用

エラー画面でコード・処理段階・対処を表示する。「診断情報」を開くと、発生時刻、公開コミットに由来するビルドID、オンライン状態、ブラウザ/ホーム画面表示、対象URLのorigin/path、観測できたHTTP状態・Content-Typeをコピーできる。設定にもビルドを表示する。

診断を自動送信・永続保存しない。URLのquery・fragment・ユーザー名/パスワード、入力HTML、材料、エラーの自由文、Cookie、認証情報、stackは診断コピーから除外する。URLのパスは含むので、共有前に確認する。コピーが許可されなければ表示された診断を選択して手動コピーできる。

`IMP-2003`だけでCORS/DNS/TLS/転送のどれかを断定しない。応答が読めない場合にHTTP 403/200/0などを作らない。HTTP状態を取得できた場合だけ記録し、取得成功後の解析失敗にはその状態と「URL応答のレシピ解析」を記録する。HTTP 403は固定コード`IMP-2004`と`httpStatus:403`で表す。

コードの定義元は`src/domain/errors.ts`。日本語文言からコードを判定しない。既存コードの意味を変更/再利用せず、新しい原因には新コードを割り当てる。予期しない共通操作失敗は`APP-9001`とし、既知の取込・検証・容量・DB読込エラーと分ける。

## コード一覧

| コード | 段階 | 意味 | 対処 |
| --- | --- | --- | --- |
| IMP-1001 | URL入力 | 元レシピのURLが正しくありません | 認証情報を含まないhttp(s)のURLを確認してください。 |
| IMP-1002 | URL入力 | 直接取得にはhttpsのURLが必要です | 元ページをブラウザで開き、httpsのURLを入力してください。 |
| IMP-1003 | 入力 | 取り込む内容が空です | URL・HTML・JSONなど、選んだ方法の入力を確認してください。 |
| IMP-1004 | 入力 | 取込データがサイズ制限を超えています | HTMLは2MB、回答・ページ取込データは100KB以下にしてください。 |
| IMP-2001 | URL取得 | 端末がオフラインです | オンラインに戻して再試行するか、保存済みHTMLを取り込んでください。 |
| IMP-2002 | URL取得 | 取得が12秒でタイムアウトしました | 通信状態を確認してください。元ページでの取込やHTMLの貼り付けも使えます。 |
| IMP-2003 | URL取得 | ブラウザが応答を読み取れませんでした | CORS・DNS・TLS・転送などが考えられます。このエラーだけでは断定できません。クックパッドは「ページ取込」の手順を使ってください。 |
| IMP-2004 | URL取得 | 元サイトがHTTPエラーを返しました | 元ページを開いてURL・公開状態を確認してください。認証やアクセス制限は回避しません。 |
| IMP-2005 | URL取得 | HTML・JSON以外の応答です | 画像やPDFではなく、レシピページのURLを指定してください。 |
| IMP-2006 | URL取得 | 取得したページが2MBを超えています | 材料だけのページ取込、または対象の構造化JSONを使ってください。 |
| IMP-2007 | URL取得 | 取得したページの本文が空です | 元ページで材料を表示してからページ取込を試してください。 |
| IMP-2008 | URL取得 | 応答の文字コードを読み取れません | ページ取込か、UTF-8のHTMLファイルを使ってください。 |
| IMP-2009 | URL取得 | 転送先のURLを利用できません | 元ページを開き、最終的なhttpsのURLを確認してください。 |
| IMP-3001 | レシピ解析 | Recipe形式の構造化データが見つかりません | クックパッドはページ取込、ほかの本文はChatGPTによる整理を使えます。 |
| IMP-3002 | 材料解析 | 材料欄を読み取れません | 元ページで材料を表示してください。ログイン画面・エラーページは取り込めません。 |
| IMP-3003 | 材料解析 | 材料名を読み取れない行があります | 欠落したまま保存しません。元ページと材料欄を確認してください。 |
| IMP-3004 | レシピ検証 | レシピの形式が正しくありません | 料理名・人数・材料・数量と単位・出典を確認してください。 |
| IMP-3005 | JSON解析 | JSONを読み取れません | 選んだ方法に合うJSON全体を貼り付けてください。 |
| IMP-3006 | レシピ解析 | 構造化データの件数や深さが上限を超えています | 材料は100件、候補は20件までです。必要なレシピだけを使ってください。 |
| IMP-3007 | ファイル読込 | ファイルを読み取れませんでした | 端末に保存済みのHTML・JSONファイルを選び直してください。 |
| IMP-4001 | 元ページで実行 | Safariのクックパッドページで実行してください | URL文字列ではなく、材料を表示したSafariの共有メニューからショートカットを実行します。 |
| IMP-4002 | ページ取込 | ページ取込データの形式または取得元が正しくありません | 実行用コードではなく、ショートカットの実行結果を貼り付けてください。入力URLと取得元も確認してください。 |
| IMP-4003 | クリップボード | クリップボードAPIに対応していません | 表示されているコードを選択してコピーするか、入力欄に手動で貼り付けてください。 |
| IMP-4004 | クリップボード | クリップボード操作が許可されませんでした | 入力欄を長押しして貼り付けるか、コードを選択してコピーしてください。 |
| IMP-4005 | 元ページで実行 | 元ページでの材料取得に失敗しました | Safariで材料欄を表示して再実行してください。材料が見えないページには対応しません。 |
| DATA-1001 | 入力検証 | 入力内容を確認してください | 表示された項目を修正して再実行してください。 |
| DATA-2001 | 端末保存 | 端末の保存容量が不足しています | 空き容量を確認してください。保存済みデータを削除する前にバックアップを残してください。 |
| DATA-2002 | 端末データ読込 | 端末の保存データを開けません | 空き容量・プライベートブラウズ・他タブの更新を確認して再読み込みしてください。データの削除は行わないでください。 |
| APP-9001 | 操作 | 処理を完了できませんでした | 入力を残して再試行してください。繰り返す場合は診断情報を確認してください。 |
